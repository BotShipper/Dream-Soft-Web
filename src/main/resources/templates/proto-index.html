📖 Hướng dẫn sử dụng

  1. Chuẩn bị file .proto: Tạo hoặc có sẵn file Proto của bạn
  2. Upload: Click vào vùng upload hoặc kéo thả file .proto vào
  3. Hoặc paste: Copy nội dung Proto vào textarea nếu không muốn upload file
  4. Validate (Khuyến nghị): Click "Validate Proto" để kiểm tra trước
  5. Generate: Click "Generate & Download ZIP" để compile
  6. Nhận file ZIP: File ZIP sẽ tự động download, chứa:
    • ✓ File .proto gốc
    • ✓ Thư mục java/ với code Java đã compile bởi protoc
    • ✓ Thư mục csharp/ với code C# đã compile bởi protoc
    • ✓ File README.txt với thông tin chi tiết
Ví dụ Proto file: syntax = "proto3"; package game.app.pb; option java_package = "game.app.pb"; option csharp_namespace = "Game.App.PB"; message DataResponse { int32 code = 1; string message = 2; bytes data = 3; } message User { int64 id = 1; string username = 2; string email = 3; repeated string roles = 4; } enum Status { UNKNOWN = 0; ACTIVE = 1; INACTIVE = 2; }
